# Claude project instructions

The canonical project-wide instructions are in [AGENTS.md](AGENTS.md). Read
and follow that file for every task; it defines documentation ownership,
repository boundaries, domain invariants, security expectations, and
verification rules.

Use the documents by responsibility:

- [SPEC.md](SPEC.md) for product features and behavior.
- [README.md](README.md) for setup and user/developer operations.
- `app/README.md` and `api/README.md` for project-specific implementation
  details.

Do not add Claude-specific rules here that conflict with `AGENTS.md`. Update
`AGENTS.md` when a project-wide engineering boundary changes.
